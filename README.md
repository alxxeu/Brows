# Brows

Brows is a native macOS browser written in fast Swift and powered by Chromium. It is quick, modern and carefully thought through: tabs live in a sidebar and are organized into Spaces, so work, study and personal browsing stay apart. Pages are rendered by Chromium, so websites behave as they do in Chrome, and extensions from the Chrome Web Store work.

**Version 0.1.1 alpha, closed test.** New builds appear on the [Releases](../../releases) page.

## Requirements
- macOS 26 or later
- Mac with Apple Silicon (M1 or newer)

## Install
Download `Brows.dmg` from the latest release, open it and drag Brows to Applications. The app is signed with a Developer ID certificate and notarized by Apple.

## What makes it different
- **Tabs live in the sidebar**, grouped into Spaces. Swipe with two fingers to flip between Spaces, each one remembers its last tab.
- **Pinned tabs, folders and favorites** keep your sites where you left them; closed tabs go to an archive instead of disappearing.
- **One command bar** for addresses, search and switching tabs.
- **Sort** tidies a messy tab list into topic groups. The grouping is done by an on-device model, nothing leaves your Mac.
- **Chrome extensions** live in the sidebar too: pin the ones you use, the rest sit in one tidy grid.

## Limitations
- No password manager or autofill, no private windows, one window
- No passkey support yet
- Safe Browsing warns about known phishing and malware sites; downloaded files are not scanned
