# Security

To report a vulnerability in Holoholo, email **alxxeu.dev@proton.me** and please do not post details publicly. Include the Holoholo version, the macOS version and steps to reproduce.

I reply within 7 days. Fixes ship in a new release; the latest release is the supported version.

Vulnerabilities in Chromium itself are fixed by updating the bundled Chromium in a new Holoholo build.
